# The Battery's Last Text to Its Charger

One line of at most 200 characters: the phone battery's final text to the charger it waited for all day.

> you said 'five more minutes' at 9am. it's 9pm, i'm at 1%, and you're still coiled under the couch. this is the last time i text first

`main.ts` (Node 22) writes that line to `/output/entry.txt`. No network, no dependencies.
